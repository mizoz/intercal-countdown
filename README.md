# intercal-countdown

Minimal INTERCAL verification repo.

`countdown.i` prints a four-step countdown as Roman numerals:

```text
IV
III
II
I
```

## Run

```sh
ick countdown.i
./countdown
```

Install the compiler on Debian/Ubuntu with:

```sh
sudo apt-get install intercal
```

## Language

The executable source is 100% INTERCAL. Markdown is documentation only.
